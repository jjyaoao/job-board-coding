# Goal Prompt

Use this prompt in Codex CLI after configuring the profile to use StepFun `step-3.7-flash`.

```text
目标：请从 0 到 1 完成一个可运行的「求职申请进度管理看板」项目，并持续执行到项目能够本地启动、构建通过、README 完整。

背景：
我是 27 届学生，正在投递暑期实习。投递公司和岗位太多，经常忘记哪些已经投递、哪些进入笔试、哪些快到截止时间、哪些需要继续跟进。所以我想做一个轻量实用的求职信息记录看板。

项目要求：
1. 使用 React + TypeScript + Vite 实现。
2. 不需要真实后端，使用 localStorage 做本地持久化。
3. 页面要简洁、清晰、适合截图展示。
4. 代码结构要清楚，组件拆分合理。
5. 最终项目必须能通过 npm install、npm run build，并能 npm run dev 本地预览。

核心功能：
1. 五个阶段看板：
   - 已投递
   - 笔试中
   - 面试中
   - 已拿 Offer
   - 已拒绝

2. 申请卡片字段：
   - 公司名称
   - 岗位名称
   - 岗位方向
   - 投递日期
   - 截止日期
   - 优先级：高 / 中 / 低
   - 当前备注
   - 下一步行动

3. 交互功能：
   - 新增申请
   - 编辑申请
   - 删除申请
   - 拖拽卡片改变阶段
   - 按优先级和截止日期排序
   - 7 天内截止的申请高亮提醒

4. 数据统计：
   - 总申请数
   - 面试转化率
   - Offer 数
   - 7 天内到期数
   - 各阶段数量分布
   - 岗位方向分布

5. 默认示例数据：
   请内置 8 到 10 条真实感较强但虚构的示例申请，例如互联网、消费、AI、游戏、金融科技等方向。公司名使用虚构名，避免真实公司争议。

6. 视觉要求：
   - 整体风格克制、实用、像真实生产力工具
   - 不要做营销落地页
   - 不要大面积渐变
   - 不要过度装饰
   - 看板卡片信息密度要合适
   - 移动端也要基本可用

7. 文档要求：
   - 写 README.md
   - 说明项目用途
   - 说明技术栈
   - 说明如何安装、启动、构建
   - 说明主要功能
   - 说明数据如何保存在本地

执行要求：
1. 请先简短规划项目结构。
2. 然后直接创建项目文件。
3. 安装必要依赖。
4. 运行构建检查。
5. 如果出现明显错误，请修复到 build 通过。
6. 最后给出完成总结，包括：
   - 创建了哪些主要文件
   - 实现了哪些功能
   - 如何启动
   - 是否通过构建
   - 哪些地方适合后续继续优化

请不要只给代码片段，要直接在当前目录完成整个项目。
```
